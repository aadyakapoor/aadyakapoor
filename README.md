### 🚀 Featured Projects

#### 📈 [Retail Demand Forecasting System](https://github.com/aadyakapoor/retail-demand-forecasting)
ML forecasting system for SKU-store demand prediction with API deployment and live dashboard monitoring.
- Built and deployed a **FastAPI REST API** serving a LightGBM model on **Render with Docker**, achieving **RMSE 7.43** across 200 SKU-store time series
- Engineered **24 leakage-safe time-series features** (lags, rolling stats, calendar flags, event signals) using shift-before-rolling validation
- Benchmarked LightGBM vs Prophet vs weighted ensembles via walk-forward validation
- Tracked **50+ MLflow experiments**; built a Streamlit dashboard for real-time forecast monitoring

`Python` `LightGBM` `Prophet` `MLflow` `FastAPI` `Docker` `Streamlit`

#### 🔁 [Customer Churn Prediction & Retention Engine](https://github.com/aadyakapoor/customer-churn-analysis-and-prediction)
Classification and retention analytics system for churn risk scoring, interpretability, and ROI-based targeting.
- Built a real-time churn scoring app achieving **ROC-AUC 0.819** and **recall 0.711** on SMOTE-balanced data
- Benchmarked Logistic Regression, Random Forest, and XGBoost — optimized for recall/ROC-AUC over accuracy
- Diagnosed a multicollinearity bug causing 0% high-risk predictions and fixed the pipeline
- Integrated **SHAP explanations** and cost-sensitivity simulation for ROI-based retention offers

`Python` `Scikit-learn` `SHAP` `SMOTE` `Streamlit`
